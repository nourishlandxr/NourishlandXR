# Nourishland biome reference library

This folder collects internal visual references and production briefs for the Nourishland living world.

Each biome folder should contain:

- numbered reference images supplied by the project owner;
- a concise `brief.md` translating the references into original production decisions;
- clear website-hero and Unity-XR requirements;
- acceptance criteria that can be reviewed without relying on the source photographs.

Reference images are research material only. Watermarked or third-party photographs must not be shipped, traced, reproduced as textures, or included in public builds.

## Production order

1. Preserve references and record what each contributes.
2. Approve the biome's silhouette, palette and focal composition.
3. Build the focused website-hero treatment.
4. Extend the same biome language into the complete Unity XR world.
5. Review visual identity and performance separately.
