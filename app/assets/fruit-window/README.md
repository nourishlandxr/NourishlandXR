# Fruit Window assets

Blender exports from the botanical review models. Pigeon pea uses the corrected individual leaflets and clustered pods. Coordinates are glTF metres, Y up. Models and textures remain embedded in GLB files. Load only the requested species. Source manifests retain mesh names, animation contracts and botanical details.

Original editable models and backups remain in C:/FILES/Projects/banyula 2026/Plants images/3d. Three.js is distributed under the included MIT licence.
