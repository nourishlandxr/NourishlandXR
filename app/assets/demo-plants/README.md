# Totem 2 botanical media

These optimized review assets were derived from the canonical Banyula image library without changing the originals.

- `jackfruit-artocarpus-heterophyllus.webp` is the exact-species Jackfruit reference.
- `lychee-red-ball-illustrative.webp` is explicitly captioned as the named Red Ball cultivar; it is not presented as an unidentified generic Lychee.
- `acacia-fimbriata-illustrative.webp` is explicitly captioned as an illustrative *Acacia fimbriata* reference; it does not identify the Totem record beyond *Acacia* sp.

No Vetiver image is integrated. The generated candidates failed morphology review because their panicles were too plume-like. The rejected originals are retained in `Plants images/Refined` for review rather than being used as authoritative plant media.
