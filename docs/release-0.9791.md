# One public website · V0.9791

Retires the duplicate `/xr/v2/` marketing website and mobile study. Old bookmarks now reach the current website, including Education, Food Forests, the complete story and the Learning Guide. Empty `/xr/` and `/app/` entries lead to Platform; project, editor, tour and demo query links retain their application context.

Twenty-three original WordPress page addresses redirect permanently to their current counterparts. The unused East Timor and sample-post pages return Gone with a matching Nourishland error page. Unknown public routes use that same design. The original WordPress records, administration and media remain stored; this release does not delete them.

The sitemap contains the twelve current public pages. WordPress sitemap addresses redirect there. Creator navigation and website handoffs use the clean current addresses. Shared files under `/xr` remain necessary application dependencies, including the active V17 experience; they are not another public website.

The explicit 46-file frontend overlay includes four small fallback entry bridges, the canonical route helper, current app entry/navigation modules, sitemap, robots and error page. A separately hashed routing plan replaces only the Nourishland-owned root configuration block. The installer preserves cPanel and WordPress bytes, saves a private configuration backup, checks for concurrent changes and rolls back if the new error route fails its public health check. API code, account records, project data, hero video and world geometry are unchanged.

Validation before publication: 1,227 project tests, frontend and website build, shell syntax, menu/Creator checks, 60 read-only HTTP checks, desktop/phone bookmark and Creator checks, and browser regressions against the exact packaged release. The actual app welcome screen displayed V0.9791. Browser emulation does not establish physical device acceptance. Public route and hash checks also run in the protected publishing workflow.

Routing references: [Apache rewrite flags](https://httpd.apache.org/docs/current/en/rewrite/flags.html), [LiteSpeed rewrite configuration](https://litespeedtech.com/docs/webserver/config/rewrite).
