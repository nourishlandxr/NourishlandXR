# LIMO connection testing · V0.9442

## Open the local preview

With the repository served on port 8000, open `http://localhost:8000/tools/limo-connection-preview.html`.
The preview uses the live LIMO model, authored combinations, Living Frame renderer and shared cell activation controller. Its garden records are clearly labelled sample data. It has separate preview storage from the AR demo.

In the AR tour, LIMO remains the final learning feature. Choose **Connect LIMO cells** at Learning 1.7. The existing PIMO/Uses connection code is retained for compatibility; it is not the new guided action.

## First walkthrough

1. Choose **1. Who shades whom?**.
2. Select **Plants & forest layers** in the controls or its highlighted cell. A new discovery appears with two parent strings following the Living Frame perimeter.
3. Choose **Attach local records** and select both sample plants.
4. Return to the discovery and choose **Connect this cell**.
5. Select **First steps & later roles**. The second discovery, **How shade changes as this place grows**, retains the parent lineage and attached records.
6. Reload. Use **Open saved discoveries** to reopen both results.

## Additional checks

- Cancel before connecting; no new discovery should be saved.
- Reconnect the same pair in either order; it should reopen the same discovery.
- Change Area through **Observe, compare or try → Area**; connections from another Area should disappear and return when that Area is selected again.
- Follow both parent buttons and reopen the discovery through the saved list.
- Record a dated observation or trial; it remains a personal notebook entry until explicitly published as a draft Project Note.
- Remove a discovery through its observation tools. Its dependent discoveries are archived; notebook records are retained. Recreate the original combination to restore its identity.
- Turn on reduced motion; reveal and travelling pulse should settle immediately.

## Device checks still required

On Quest, confirm controller selection hits the visible source and target, does not activate twice on release, and opens generated cells. Move/reorient the Living Frame and verify cells, strings and pointer hits remain aligned. Check text size and contrast in the actual headset.

The desktop preview and automated ray checks do not establish physical headset performance or readability.
