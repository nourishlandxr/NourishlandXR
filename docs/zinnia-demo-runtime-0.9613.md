# Demo Zinnia runtime check

Zinnia's demo perch continues to use the actual character guide, active narration analyser, paragraph cues, controller rays and tracked fingertips. The new `/tools/preview-zinnia-demo-live.html` runs the production native WebGL frame/perch renderers with a real saved demo recording and the project narration/paragraph flow. It exposes measured speech level, mouth motion, pause state, touch reaction and GL status, rather than synthesizing an audio envelope.

The main demo now includes Zinnia in its nearest-target resolution. A trigger on her produces her reaction and a haptic tap before intro controls can consume that same selection. A nearer panel remains the target. Selecting her does not interrupt the narration; the giggle only plays outside current narration.

The two branch roots were approximately 6.5 cm from the actual brown frame surface despite satisfying the old annular-volume test. Their roots now overlap the wood. The attachment regression check measures triangle distance against both actual SD and HD assets at initial, intermediate and mature growth poses, including the native renderer's 12 mm depth offset.

The native render check confirmed real recorded audio produces speaking morphs with no GL error; pause reduces both audio input and mouth motion to zero. Moving the viewer changes her gaze and leaf poses. The original silent layout previews remain useful for composition, but are not evidence of audio integration.

Version 0.9613 is a local build. Headset playback, latency and physical touch still require Quest verification; this document does not imply deployment.
