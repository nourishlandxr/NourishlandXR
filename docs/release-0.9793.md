# V0.9793 — Creator essentials

Hillyards now presents its original Garden and Tunnel animations automatically, with a crossfade between scenes. Playback pauses off-page, in a hidden tab, or behind the main menu. Reduced-motion preferences retain the still image. No video player controls are shown.

The PIMO editor starts with the original six knowledge families and stable reader IDs. Full plant records open with the six families visible, revealing their children on selection. Preview uses the actual honeycomb reader and includes draft edits. In Project knowledge, select a plant and choose **Open honeycomb editor** for a linked editor with an explicit **Save to plant** action. Existing sources, provenance and node IDs are retained; changed topics remain drafts. Revision conflicts keep the current editor open. Standalone demo canvases remain local and exportable.

The placement practice opens the Orb directly into plant knowledge. Notes offer typed editing in screen/DOM-overlay modes without requesting speech or microphone access. The placement target avoids the open options panel. The main narrated demo remains separate.

Screen Totems and the project style selector now resolve the same selected style as the shared XR renderer. All eight shared Totem designs were audited against the existing deployed geometry. This release covers the WebXR project; it does not update the separate Unity application.

Validation: full suite 1,232 passed; targeted PIMO regression checks passed after final refinements. Automated desktop and Android browser checks cover animation playback, honeycomb preview, linked saves and revision conflicts. Placement browser checks cover Orb opening, Note editing with zero speech/microphone requests, and Totem signs. The actual welcome badge shows V0.9793. Physical Quest and Android AR validation remains pending.

Publication uses the existing protected root overlay workflow with explicit file hashes and private backup. Backend, project data, routing, hero media and world geometry are outside this release.
