How automatic terrain data would flow

  1. Match the project place or drawn boundary to an NPWS area and park-map sources.
  2. Fetch NSW Spatial Services bare-earth DEM tiles or contour features for that footprint; record resolution, vertical datum, capture date and source.
  3. Reproject to a local map plane, crop, resample to a light mesh, then derive the profile and contour lines.
  4. Join named roads, waterways, tracks and places from authoritative map layers; retain each feature’s source and confidence.
  5. Cache the result as a versioned map package. Refresh only when the project boundary or source data changes; keep the schematic fallback if retrieval fails.

For this example, NPWS places Brindle Creek track in the Sheepstation Creek precinct and describes short steep hills. Its park map warns that it does not provide detailed topography. Elevation should therefore come from the NSW elevation service, not be inferred from the visitor map.
